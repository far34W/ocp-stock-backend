# OCP Stock Backend

Laravel REST API for the OCP Stock Management System.

## Features

- Authentication
- Product Management
- Category Management
- Supplier Management
- Stock Movements
- RESTful API

## Technologies

- Laravel
- PHP
- MySQL
- Eloquent ORM
- Sanctum

## Installation

```bash
git clone https://github.com/far34W/ocp-stock-backend.git
```

```bash
composer install
```

```bash
cp .env.example .env
```

```bash
php artisan key:generate
```

```bash
php artisan migrate
```

```bash
php artisan serve
```
